## 本店已确认口径优先于扣子清单

1. 正式启用后以飞书进销存后端为**唯一库存与交易主账**；管家婆仅作为历史迁移和核对来源。测试数据不得作为真实期初。
2. 实际退货和错账更正须留原单、用可追踪的冲销或补正记录；不得直接擦改历史，也不能为了“零红冲”禁止必要更正。
3. 接待有效性、加微信和协助积分由老板逐单核定；无效接待最低 50 分。协助提成按净毛利 1%–3%，从原销售人的提成中分出。
4. 移动佣金发放、资费与国补办理以用户后续提供的原始规则、平台页面和真实结算单为准；不把扣子稿的固定比例或罚款直接写成正式规则。

## 下一轮开发与验收顺序

1. 测试/正式账套隔离、正式期初复核、串码与数量盘点、一键备份及隔离环境恢复演练。
2. 按账户导入或登记外部支付流水，匹配原单，处理差异，完成交接双方确认、老板复核和营业日锁期。
3. 客户应收、原单核销、复式凭证草稿、总账与月结报表；移动和国补按真实结算单对账。
4. 组合收款、搜索与下拉、扫码、票据识别草稿和打印。
5. 接扣子 AI：先只读查账和填单草稿，保留资料来源与人工修改记录，通过准确性验收后扩展顾客机器人。

每项验收至少保留正常单、异常/退回单，以及库存、资金、工资影响和飞书通知证据。本清单不代表正式财务软件验收通过。

# 固定功能代码规则

每个已经确认的业务功能使用一个固定的英文代码。代码表示业务动作，不表示页面上的中文名称。中文名称、说明文字、菜单位置可以调整，不能因此改变代码指向的动作。

## 当前确认的代码

| 功能代码 | 当前显示名称 | 固定含义 |
| --- | --- | --- |
| `reception.home` | 接待与跟单 | 展示接待事项入口 |
| `reception.mine` | 我的接待单 | 查看本人既有接待单 |
| `reception.create` | 新的接待单 | 登记本次接待 |
| `reception.voice` | 语音接待 | 用语音整理草稿，核对后建单 |
| `reception.followups` | 我的跟单 | 查看本人待回访及已有跟进记录 |
| `sale.open` | 销售开单 | 建立销售单 |
| `sale.item.manual_serial` | 手工选串号 | 从当前在库手机选定具体串号并核对真机后四位 |
| `sale.item.scan_serial` | 扫码选串号 | 从扫码结果定位具体在库手机 |
| `display.large_text.toggle` | 大字版／标准模式 | 切换文字大小 |

## 实施边界

1. 路由、按钮动作、权限、日志和测试按英文代码识别，不按中文文案判断。
2. 改名只改显示文本和无障碍说明；旧链接、旧单据号和存量数据继续有效。
3. 功能含义确实变化时新增代码，不复用旧代码；保留旧代码兼容映射和迁移记录。
4. 同一业务动作从入口、提交到审计日志使用同一代码，记录来源单号与执行结果。
5. 回归检查：只改中文名称后，点击目标、权限、请求、单据结果均保持一致；页面耗时单独测量。

当前接待入口的路由值 `mine`、`new`、`voice`、`followups` 作为已发布兼容值固定使用。现有销售按钮的 `data-action` 也是固定英文动作值。后续改动按此表扩展，并逐步清点旧页面中直接依赖中文文案的判断。

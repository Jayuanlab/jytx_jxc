# 移动业务与国补接入说明（测试期）

更新：2026-10-07。飞书进销存为主账；当前数据仍是测试账，正式使用前需盘点与结算单核对。

## 移动业务

业务类型：号卡、充值、宽带、套餐。每笔记录移动系统业务编号、经办人、办理日、可选关联销售单，次月起至第六个月逐月填写**预计结算金额**。确认移动结算单后生成**已确认待到账**，银行/平台到账凭证登记后生成**实际到账**及资金流水。预计、确认、到账三种金额始终分列；不因预计金额自动确认收入或现金。

`移动业务发放规则与国补规则_复核稿_20261007` 提到宽带 100%/200 元封顶、终端合约 3 倍/6 个月、套餐升档倍数、员工移动提成 20% 等。这些来自扣子复核稿，其所引移动资料原件尚未收到，暂不写死自动计算。收到移动结算表和原始规则后，按规则版本、生效日期、业务类型建立模板；每笔仍可由平台账单复核。员工提成发放时点、跨人协作归属尚待店主确定。

## 国补销售

开单分“普通销售 / 国补销售”。国补通道只允许单件、已登记串码、政策覆盖品类；售价不超过 6000 元，补贴不超过成交价 15% 且每件不超过 500 元。须录入外部平台交易号和实际核销补贴金额。销售额按完整成交价，顾客云闪付实收为成交价减补贴；补贴金额进**国补在途台账**，平台结算确认及实际到账另记。系统不代替云闪付的顾客资格校验、核销、发票与平台退货操作。

国补退货只支持整单。先取得平台退款流水号，本系统记录顾客原渠道退款与补贴原渠道冲退；如果补贴已到账，另登记退回补贴的实际付款流水。不能把补贴部分当成给顾客的现金退款。

示例：售价 1099 元、补贴 164.85 元，顾客实付 934.15 元；若整单退货，顾客退 934.15 元，补贴 164.85 元按平台原渠道冲退。该数值来自扣子稿例子，仅作测试，不代表真实交易。

## 复核稿需纠正的表述

- “云闪付顾客实付必须等于真实成交价”应改为：**顾客实付 = 真实成交价 − 已核销补贴**，发票及平台凭证分别列示成交价、补贴与实付。
- “全额退款后当年补贴资格直接作废”与重庆市 2026 年通知不符：通知写明完成全额退款后，系统将在 7 个工作日内自动恢复该消费者对应类别资格券申领权限，可在下一发券周期重新参与。实际资格状态仍以平台为准。
- “宽带/套餐倍数/员工提成”原件未核实，不能把扣子稿当作自动计算依据。

官方依据：[重庆市2026年家电及数码智能产品购新补贴通知](https://sww.cq.gov.cn/zwgk_247/zfxxgkml/qtfdxx/tzgg/202512/t20251231_15284847.html)、[重庆市补贴资金审核兑付流程指引](https://sww.cq.gov.cn/zwgk_247/zfxxgkml/qtfdxx/tzgg/202601/t20260130_15367242.html)。
